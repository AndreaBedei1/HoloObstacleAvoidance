# Figures

Every figure in the paper must be regenerated by a committed script reading
committed experiment manifests (`experiments/**/manifest.json` + per-run
JSON). No hand-edited images of results.

Planned figure inventory (updated as experiments land):

- fig_system_architecture: same-code sim/real stack diagram
- fig_calibration_ladder: S0–S3 what-is-calibrated table/diagram
- fig_step_response: sim vs real surge/sway/yaw step responses per S-level
- fig_estimator_consistency: NIS + 1σ/2σ coverage, per estimator, per domain
- fig_trajectories: representative sim & real avoidance trajectories (overhead)
- fig_sim_real_gap: per-metric gap vs calibration level
- fig_ranking: SRCC of method rankings vs calibration level
- fig_ablation: closed-loop outcomes per estimator/planner stack
