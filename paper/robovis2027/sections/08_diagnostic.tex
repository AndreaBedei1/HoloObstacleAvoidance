\section{Post-Deployment Diagnostic Simulation \diagmark}
\label{sec:diagnostic}

\subsection{Design and provenance}

All simulations in this section were designed and run after the physical
campaign, with its outcome known. They are diagnostic evidence
(\diagmark), never pre-deployment predictions.

The frozen 80-run aggregate is unsuitable as an ablation baseline because
its stochastic seed is not reproducible and its loaded execution rate
differs from an idle rerun (Section~\ref{sec:limitations}). We therefore
ran a self-contained 80-run ablation: eight configurations, ten
repetitions each, all using the committed planner, \textsf{K0} and S3.
A0 reproduces the frozen configuration in the same session. A1--A6 each
change only the listed factor relative to A0; A7 combines A1--A6.
Comparisons use medians, interquartile ranges and counts because the
outcomes are bimodal.

basin; it is neither an executed configuration nor an exhaustive search
over basin-compatible manoeuvres.
